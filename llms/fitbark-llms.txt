# FitBark API

> The FitBark API enables developers to integrate FitBark dog activity and health data into third-party mobile and web apps. It exposes a dog's activity series and totals, time-at-activity breakdowns, daily goals, similar-dog statistics, related users and dogs, and profile pictures. Authentication is OAuth 2.0; client_id/client_secret are issued to approved developers on application.

## APIs

- [FitBark API v2](https://www.fitbark.com/dev/): OAuth 2.0 REST API over dog activity, goals and profiles (base https://app.fitbark.com)
